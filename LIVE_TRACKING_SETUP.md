# CampusDine Smart Order Tracking + Rider GPS

Smart Order Tracking remains available to students and teachers: Received → Cooking → Ready, ETA, status history/timestamps, notifications, Socket.IO updates and refresh after reconnect. Student order pages do not show GPS.

Rider GPS is separate and is visible only to authenticated teacher accounts. The rider must choose Start GPS sharing on their rider dashboard. The browser sends current location every 8 seconds while sharing is active.

See `RIDER_TRACKING_SETUP.md` for login and test instructions. Browser location permission requires HTTPS or localhost.
