# Images

Where the pictures in `frontend/images/` are used.

## Food pictures (`frontend/images/food/`)

Each menu item points to one of these SVG files. Items without a matching picture use `default.svg`.

### `beef-bhuna.svg`
Used by: Beef Bhuna & Rice, Beef Curry & Rice, Beef Rezala

### `borhani.svg`
Used by: Borhani

### `cha.svg`
Used by: Cha (Tea), Ginger Tea, Green Tea, Iced Lemon Tea, Lemon Tea, Masala Tea

### `chicken-biryani.svg`
Used by: Chicken Biryani, Chicken Biryani Half, Chicken Roast, Polao & Roast

### `chicken-burger.svg`
Used by: Beef Burger, Chicken Burger, Chicken Cutlet, Veg Burger
