# Changelog

## Unreleased
- Chat: Hall students/teachers now have a separate **Hall Admin chat** (Hall → "Hall Admin chat"). It goes only to the Hall Admin, who reads and replies from the Hall Admin portal ("Student messages"). The canteen chat inside each restaurant still goes only to the canteen admin. New `scope` (`canteen` or `hall`) on the chat API, `GET /api/chat/directory`.
- Chore: the helper and patch scripts moved from the project root into `tools/`.
- Config: `TRUST_PROXY` makes the login lock-out count per visitor when the server is behind a reverse proxy.
- Performance: the Lost & Found screen no longer downloads every photo on each 15-second refresh (`?images=0` plus `GET /api/campus/lost-found/:id/image`).
- Privacy: `GET /api/riders/locations` shows a position only while the rider is sharing it.
- Security: changing the email address now needs a code sent to the new address (`POST /api/auth/me/email-code`, then `emailCode` in `PUT /api/auth/me`).
- Coupons: `migrations/20261101_prize_coupons.sql` creates TEHARI10, STUDY15, FREECHAI and CASH5, the codes the spin wheel and scratch card show.
- Menu: 15 more items in `more_menu_items.sql` (Waffle, Hot Dog, Chilli Chicken and others) and calories for 3 of them.
- Docs and tests: group orders, weekly orders, Hall meal states and fraud events.
- Fix: Hall pickup-token routes use the canteen date between 00:00 and 06:00.
- Fix: changing the account e-mail now requires the current password.
- Fix: demo accounts (admin/admin123 and others) are no longer created when NODE_ENV=production.
- Fix: wallet top-up is now limited to student and teacher accounts (riders and admins could call it before).
- Menu: calories and allergens for 28 more items, with tests that check the data.
- Menu: `more_menu_items.sql`: 60 more items (132 in total) with Bangla names, prices and restaurants.
- Fix: Hall Admin login is locked for 10 minutes after 5 wrong passwords.
- Fix: Hall Admin notices (no university) are now visible to students assigned to a university.
- Fix: wallet top-ups are limited to a daily total per account (default ৳20,000).
- Fix: Lost & Found photos are validated in full and escaped in the Hall Admin page (stored XSS).
- Docs: `docs/HALL_ADMIN_API.md` covers the Hall Admin sign-up, login with e-mail code, requests, notices and dashboard.
- Fix: visitor requests and hall pickup tokens used the UTC date, so between 00:00 and 06:00 in Dhaka they used yesterday. They now use the canteen clock (`todayKey()` in `utils/clock.js`).
- Docs: `docs/HALL_ADVANCED_API.md` covers rooms, visitors, facilities, clearance, laundry, notifications and university routes.
- Docs: `docs/HALL_API.md` lists every `/api/hall` route with who can call it, limits and error codes.
- Docs: riders API guide.
- Fix: wallet transfer now rounds the balance it returns, so it can no longer show values like 60.199999999999996.
- Tests: money helper tests.
- Tests: one-time code (OTP) rules with an in-memory database, and catchAsync.
- Docs: auth API guide.
- Fix: coupon routes now always release their database connection. Before, an error such as a duplicate code leaked one, and about ten errors could freeze the server.
- Fix: `/api/coupon/apply` now checks active, expiry, usage limit, minimum order, one use per person and one discount per order, and caps the discount at the order total.
- Fix: creating a coupon now validates the input and returns 409 for a duplicate code.
- Docs: coupon API guide. Tests: coupon rules.
- Docs: pricing guide.
- Tests: combo and happy-hour pricing tests with a fake database.
- Fix: admin order filters now reject impossible dates such as 2026-02-30.
- Docs: architecture overview.
- Tests: edge cases for order rules.
- Docs: Campus Command Center API guide.
- Tests: catalog tests, including a check that every menu image file exists.
- Docs: wallet API guide and corrected top-up limit.
- Tests: new unit tests for diet tags and hall cut-off helpers.
- Hall weekly menu: sample meals now include sides such as salad, banana and lemon.
- `more_menu_items.sql`: 47 more items across the four restaurants.
- Hall menu screen: input label and placeholder, loading text, and a guard for missing weekdays.
- Hall styles: focus ring, hover effects and reduced-motion support.
- Pages: meta descriptions and theme colour; Hall Admin favicon and form labels.
- Repo: `.editorconfig`, `.gitattributes`, `npm test` script and a corrected `.gitignore`.
- Docs: hall menu guide, menu SQL guide, environment variables table, FAQ and contributing guide.
